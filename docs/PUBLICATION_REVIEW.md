# Public source review

This allowlisted copy includes the functioning application, synthetic data, tests,
verification/report tools, font licenses and neutral research documentation. The
original local workspace and evidence were preserved. Personal submission details,
raw conversations, machine-specific inspection notes, old archives, raw test XML,
reference-site screenshots, vendor packages, caches and private captures are excluded.
Loopback addresses in code and run instructions are intentional; negative network
test fixtures are fictional. No real credentials or private endpoints are included.

The research engine, tests, scientific data and font binaries retain their original
bytes. Public preparation changes documentation, the neutral competition-status
label and report/package status text. Source hashes differ from the earlier local
version for those reasons. Fresh verification is required for the public copy.
The verification wrapper also creates its temporary parent directory, fixing a
fresh-checkout failure found during public-copy validation. The earlier failed
test receipt remains local; scientific inputs and results are unchanged.
The immutable baseline manifest is retained and does not assert that omitted local
files are published. An initial publication commit does not reconstruct development
history. This release makes no new novelty, empirical-model or eligibility claim.
