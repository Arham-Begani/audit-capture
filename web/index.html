    04 / THE EDGES OF THE CLAIM

    Useful questions.
    Honest boundaries.

    This testbed isolates a review-allocation mechanism. It does not establish that deployed agents discover the strategy, that real monitors produce these scores, or that multiple agents outperform one.

    Uniform sampling, fair allocation and holding sensitive actions each have costs. Negative results are retained. Independent random sampling is not a complete defense. Where trusted authorization is cheap, checking grants directly is stronger.
